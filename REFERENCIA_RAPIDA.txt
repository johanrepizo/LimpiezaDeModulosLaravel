📊 FLUJO PRINCIPAL
═══════════════════════════════════════════════════════════════════════════════

SETUP:
  1. Admin → Crear Programa
  2. Admin → Crear Ficha (asociada al programa)
  3. Admin → Crear Módulo
  4. Admin → Asignar Módulo → Ficha
     (⚡ Genera 104 turnos automáticamente)
  5. Admin → Activar Vocero
     (⚡ Crea usuario ap{id}@sena.edu.co)

CICLO SEMANAL:
  1. Vocero → Crear Grupo (selecciona integrantes)
     (⚡ Sistema asigna próximo turno libre)
  2. Vocero → Subir Evidencias (foto ANTES + DESPUÉS)
     (⚡ Turno pasa a Cumplido)
     (⚡ Grupo avanza al siguiente turno)

MONITOREO:
  1. Admin → Ver Dashboard
  2. Admin → Ver Evidencias
  3. Admin → Ver Notificaciones

Tablas principales:
  • roles              → Admin, Vocero

  • log_sincronizacion → Logs de sincronización

⚙️  SERVICIOS Y LÓGICA
═══════════════════════════════════════════════════════════════════════════════

TurnoService:
  • generarTurnosAsignacion()    → Crea 104 turnos (2 años)
  • avanzarTurnoGrupo()          → Rota grupo al siguiente turno
  • proximaFechaLibre()          → Obtiene próximo turno libre
  • cerrarTurnosVencidos()       → Cron: marca sin evidencia
  • abrirTurnosHoy()             → Cron: abre turnos de hoy

GrupoService:
  • crearGrupo()                 → Crea grupo con integrantes
  • editarGrupo()                → Modifica integrantes
  • proximoNombreGrupo()         → "Grupo 1", "Grupo 2"
  • renumerarGrupos()            → Renumera tras eliminación

EvidenciaService:
  • procesarUpload()             → Valida y almacena foto
  • guardarEvidencia()           → Inserta en BD
  • guardarSnapshotIntegrantes() → Snapshot de participantes

AuthService:
  • validarCredenciales()        → Valida usuario/contraseña
  • validarContraseña()          → Valida requisitos
  • aplicarBloqueoTemporal()     → Bloquea tras 3 intentos
  • verificarBloqueado()         → Verifica si está bloqueado
  • generarContraseñaAleatoria() → Genera password segura

═══════════════════════════════════════════════════════════════════════════════
📌 NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

1. BD MYSQL:
   - Crear base de datos gestion_limpieza ANTES de migrar
   - Ejecutar migrations con --force para development

2. VOCEROS:
   - Máximo 2 activos por ficha
   - Usuario automático: ap{id}@sena.edu.co
   - Contraseña temporal de 10 caracteres

3. TURNOS:
   - 104 turnos = 2 años (104 semanas)
   - Se generan automáticamente al asignar módulo
   - Respetan el día de semana seleccionado

4. EVIDENCIAS:
   - 2 fotos obligatorias: ANTES + DESPUÉS
   - Máximo 10 MB cada una
   - Se almacenan en storage/app/public/uploads/evidencias/

5. GRUPOS:
   - Rotan automáticamente al siguiente turno libre
   - Se renumeran al eliminar otros grupos
   - Historial de cambios registrado
